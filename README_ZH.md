# Waveshare DA7212 Audio Board (A) 产品

[English](README.md)

DA7212 Audio Board (A) 是一款可以搭配树莓派使用的扩展板，强大功能，板载 DA7212 立体声编解码芯片，最高支持 96KHz 采样频率与最高支持 24bit 分辨率，板载标准 3.5mm 耳机接口、 3.5mm AUX 输入接口、麦克风与多类型喇叭接口方便用户使用。

- [购买链接](https://www.waveshare.net/shop/DA7212-Audio-Board-A.htm)
- [产品文档](https://docs.waveshare.net/DA7212-Audio-Board-A/)
